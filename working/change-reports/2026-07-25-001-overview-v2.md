# MBT1 Perspective Overview v2

- Date: 2026-07-25
- Scope: `DataCenter/Overview`

## Result

The configured Perspective root page now presents a richer utility-to-branch
one-line overview based on the supplied conceptual wireframe and the actual MBT1
electrical and tag models.

## Changes

- Rebuilt `com.inductiveautomation.perspective/views/DataCenter/Overview/view.json`.
- Displayed Utility1, MSG1, PDU1, Transformer1, the 208 V output bus, and all
  four Way/PowerMeter branches.
- Replaced conceptual point names with modeled voltage, current, frequency,
  power, load, efficiency, temperature, power-factor, health, communication,
  and breaker-state bindings.
- Added equipment-card navigation to the existing detail routes.
- Fit the coordinate view to an 1120 px desktop canvas so all four branch cards
  remain visible beside the shared navigation dock.
- Retained `/` → `DataCenter/Overview` in Perspective page configuration.

## Verification

- Parsed the completed `view.json` successfully.
- Extracted 69 unique `tag()` bindings and compared them with
  `working/UDT/MBT1_epms_points_list.csv`; no model mismatches were found.
- Restarted the Ignition container without removing volumes and loaded the live
  configured Perspective route in Chromium.
- Observed current values at every modeled hierarchy level and all four branch
  cards.
- Clicked the Utility card and observed navigation to `/Utility`.
- Confirmed touched Perspective resources retained UID/GID `2003:2003` and mode
  `664`.

## Follow-ups

- The Overview uses substantial inline visual styling. A later policy update
  requires future new screens and redesigns to use `sg-simple`; this report does
  not claim the Overview has been migrated to that style-class family.
